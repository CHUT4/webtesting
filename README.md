# School Profile Website

A web development project focused on creating a school profile website to provide information about the institution, its activities, and its educational environment.

## About the Project

This project was developed as part of a self-learning and web development exploration process. The website was built using the **ATM (Amati, Tiru, Modifikasi)** approach, a learning method involving observation, reference analysis, and independent implementation with modifications to suit the project's requirements.

The project was developed before the widespread adoption of AI-assisted development tools, providing hands-on experience in understanding website structures, implementing web components, and solving development challenges independently.

## Project Objectives

- Explore and practice website development.
- Understand the structure and components of a school profile website.
- Apply web development concepts through practical implementation.
- Improve technical skills through independent experimentation and modification.

## Development Approach

The development process involved:

1. **Observation:** Studying existing school profile websites as design and structural references.
2. **Adaptation:** Understanding and implementing relevant layouts and website components.
3. **Modification:** Adjusting the implementation to meet the project's needs and objectives.
4. **Testing:** Exploring website functionality and checking the implementation.

## Project Status

This repository is maintained as a web development learning and experimentation project.
